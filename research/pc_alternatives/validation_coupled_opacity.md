# 有限光深、复合与多源辐射的耦合修复

2026-10-23。实现 [`coupled_opacity.py`](coupled_opacity.py)，数值证据见
[`validation_coupled_opacity.json`](validation_coupled_opacity.json)，复现程序为
[`validation_coupled_opacity.py`](validation_coupled_opacity.py)。生产 `global-budget` 未变。

这里修复的是研究路径中“复合后追加容量、未填满的单元完全不透明”的物理闭合误差。
新求解器针对**固定密度、固定温度、纯氢、局域 case-B 复合、无限光速、给定无环射线**。
每格为均匀混合介质，采用有限光深吸收；同一格可接受任意多个源及相反方向的入射。
它尚不是完整 Qin20 热反馈与密度演化方案，也没有取代原来的无复合锐前沿核。

## 1. 耦合方法

单格的中性比例为 y=1−x，氢原子数 N，中性光深 τ₀。一个光束在时间区间内的入射
光子数为 U，纯光电离子流具有精确解：

\[
y_1={1\over\tau_0}\log\left[1+(e^{\tau_0y_0}-1)
 e^{-\tau_0U/N}\right],\quad
A=N(y_0-y_1),\quad U_{\rm out}=U-A.
\]

沿一条不重复经过单元的有序射线，用上一格的累计透射 U_out 作为下一格的累计入射。
由于该单元的纯光电离只依赖累计入射量，即使上游透射率随时间变化，整条单光束子流仍是精确的。
吸收量使用 `log1p`/`expm1`/`logaddexp` 的稳定表达直接计算，避免接近的中性量相减。

复合子流也是精确的：x₁=x₀/(1+αn_H x₀Δt)。
对所有光束及复合子流作回文顺序的 Strang 组合，使共享单元中的同时竞争在时间步缩小时
以二阶收敛。每个子流有非负吸收、透射和复合，状态保持 0≤x≤1。
每一光束、每一单元的光子/原子账本分别累计；不通过全局重标定修正。

`path_tau` 为每条射线每一段提供不同的 τ₀，因而可以接受真实 DDA 交段长度。
单条射线重复进入同一格会形成反馈环，破坏此处单光束精确解的三角结构，目前明确拒绝。
不同光束之间可以构成相反方向耦合，已与同时积分的 ODE 比较。

默认进行一个完整步与两个半步的比较，接受两个半步的结果，不作可能破坏正性的 Richardson 外推。
给定 `rtol/atol` 控制的是**局部误差估计**，不是全局数学误差上界；结果同时记录实际独立参考误差。
耗尽 `max_steps` 会抛出异常，而不会返回“已经达到精度”。极端尺度下，若 float64 电离比例无法
表示新增原子数，默认也拒绝结果；诊断模式保留直接计数 `ionized_atom_increment` 并标记未分辨。

## 2. 时间与源历史验证

参照解采用独立的同时耦合 ODE，逐束计算 Beer–Lambert 吸收，并用 Radau 与 DOP853 交叉核对。
参照解之间的最大电离比例差为 `3.47e-13`。

| 案例 | 新方法的最大 Δx，rtol=1e−8 | 固定步渐近时间阶 |
|---|---:|---:|
| 复合中的单格，τ₀=1 | `1.30e-8` | 1.99988 |
| 两束共同照射屏幕后分支 | `1.70e-8` | 1.99974 |
| 两束反向经过两个格 | `8.22e-9` | 1.99962 |
| 高光深屏幕，τ₀=1000 | `2.43e-8` | 1.99223（2048→4096 步） |

原来的失败案例，在 t=2 时追加容量法始终得到 x=1、透射=0。
新方法恢复参照值 **x=0.5918932719，累计透射=1.4610429566（总入射2）**。
共享屏幕的误差也随时间细化消失，而不是保持原来约25.8%的吸收分配偏差。

光束排序对有限步结果仍有影响，这是可测的分裂误差：8、16、32、64、128 步的最大排序差
依次为 `9.19e-4、2.31e-4、5.79e-5、1.45e-5、3.62e-6`，每次细化约缩小4倍。
实际接口在“开启→关闭→重新开启”三个源阶段保留气体状态，并重新计算当前遮挡，
最终最大 Δx=`1.24e-8`。关源时恢复 x=x₀/(1+αn_H x₀t)，重新复合的屏幕会再次吸光。
各阶段的输入是发射率与持续时间，不会再次注入累计源预算。

对应的即时有效光电离率采用

\[
\Gamma_i={\sum_b F_{bi}[1-e^{-\tau_{bi}(1-x_i)}]\over N_i(1-x_i)}.
\]

当 x→1 时，稳定使用有限极限 Σ_b F_bi τ_bi/N_i；不沿用 ES 首次跨阈值给出的 Γ。
该 Γ 的定义与本模型中的吸收/原子更新一致，但没有额外导入原生自屏蔽或热反馈。

## 3. 空间验证

平行光、无复合、固定截面/氢密度的平面薄层具有解析的累计中性柱密度。
新方法在2至64格下直接恢复每个单元的**体积平均电离比例**，最大误差 `9.52e-15`，
总吸收与透射也不随划分变化。这比把格心值当成格平均值的比较更严格。

加入复合后，局部 x² 的空间平均会产生真正的离散误差。
采用总光深20、αn_H=0.7、t=1.5，独立 DOP853 在1024格上的同时解作参考。
512→1024 格的参考变化为 `1.85e-7`（体积加权 x 的 L1）。

| 格数 | 体积加权电离比例 L1 误差 |
|---:|---:|
| 4 | `3.219e-3` |
| 8 | `9.539e-4` |
| 16 | `2.485e-4` |
| 32 | `6.271e-5` |
| 64 | `1.568e-5` |
| 128 | `3.879e-6` |

充分分辨后接近二阶。这里验证的是一维薄层上的空间闭合；多维角覆盖、点源位置、
复杂遮挡及周期重复穿越仍需各自验证，不能由此表格代替。

## 4. 成本与范围

常见三格控制在 rtol=1e−6 时约0.1–0.2秒，rtol=1e−8 时约0.7–1秒，均为 Python 研究核。
高光深 τ₀=1000 的严格控制需要约38956个已接受步；最终JSON计时约8.6秒，较早共享主机测量约15秒。128步时仍有约0.00446的电离比例误差。
这些结果表明正性和守恒不足以保证大时间步准确，且该通用分裂方案目前不具备“高光深下也低成本”的证明。

浮点精度不足拒绝、无环真实长度接口。尚缺：有限光速与化学的一体耦合、频谱/氦/温度、密度输运、
