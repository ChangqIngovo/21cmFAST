## Reproduce the independent tests

Requirements: Python3.12+, NumPy, SciPy, pytest, gcc/g++, OpenMP for angular
experiments, and matplotlib for figures. The native fixture preparation also
requires a built checkout of this 21cmFAST branch and its normal dependencies.
Shared libraries are compiled into temporary directories, not checked in.

From the repository root:

```bash
python -m pytest -q research/pc_alternatives
```

Original research drivers:

```bash
python -m pytest -q research/pc_alternatives/test_fft_allocation.py \
  research/pc_alternatives/test_hybrid_flux.py \
  research/pc_alternatives/test_event_front.py
python research/pc_alternatives/counterexamples.py
python research/pc_alternatives/event_front_audit.py
python research/pc_alternatives/event_geometry.py
```

Individual drivers expose `--help`. Some historical JSON files intentionally
record earlier prototype versions; source hashes and timing qualifications
identify them. The optimized event benchmark is a separate result from its
initial version. Do not replace a failed test by an unrelated easier one.
