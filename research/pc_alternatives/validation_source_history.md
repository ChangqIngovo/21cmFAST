# 瞬时源历史与跨步发射账本：修复和验证

本轮候选明确选择 **对瞬时 SFRD 光子发射率积分** 的时间模型。生产
`global-budget` 保留原有累计源定义，不受此研究接口影响。

## 修复了什么

`source_history.py` 增加可直接调用的接口：

- `RateHistory.from_knots(times, rates)`：在时间节点间作非负线性插值，精确积分这个插值模型。
- `RateHistory(times, left_rates, right_rates)`：每段分别给定左右极限，准确表示源的开启、关闭和跳变；不把跳变平滑成斜坡。
- `SourceLedger.advance(stop)`：只返回上次时刻到本次时刻的**新发射量**。重复调用同一时刻返回零，后退时刻拒绝执行。
- `checkpoint()` / `from_checkpoint(...)`：保存时间游标、源历史指纹、时间定义、固定原子场指纹和补偿累计量。继续计算时不再支出过去的累计光子。
- `RateHistory.append(...)` / `SourceLedger.extend_history(...)`：反馈计算提供下一时段的源率后，可继续追加未来历史；必须完整保留已有前缀，不能回写已经使用的源。
- `native_sfrd_history(...)`：使用已核对的 Qin20 瞬时 SFRD 单位与产额/逃逸率转换，不再乘一次密度，不归一到旧的累计 `nion` 差。

新增量直接积分计算，避免“大累计量相减求小增量”。先累计 `1e20`，下一步发射
`0.001`，新返回量仍为 `0.001`；补偿累计量的低位部分也保存在检查点中。
负发射率、负时间段、无穷或超范围预算都会报错，没有把负累计场差裁成零。

这是发射账本，不是输运状态。有限光速的在途光子仍须由输运求解器保存。
`SourceLedger` 采用固定气体场；传入变化后的原子场会报错，直到另有守恒的密度平流/重映射实现。

```python
from source_history import RateHistory, SourceLedger

# t=1 关闭源；明确跳变，保持正确的累计发射量。
history = RateHistory([0, 1, 3], [[2.0], [0.0]], [[2.0], [0.0]])
ledger = SourceLedger(history, atoms=[100.0])
first = ledger.advance(0.5)       # [1.0]
saved = ledger.checkpoint()
ledger = SourceLedger.from_checkpoint(history, [100.0], saved)
fresh = ledger.advance(3.0)       # [1.0]，不是累计 [2.0]
repeat = ledger.advance(3.0)      # [0.0]
```

## 时间准确性

15 项单元测试通过，包括不规则时刻、分步一致性、源关闭/重启、检查点、因果追加历史、单位缩放
`1e-120` 至 `1e120`、小量发射、端点和溢出检查。另有 64 组随机分段线性且可跳变的
源历史；任意细分时间段后，累计积分的最大相对差为 `1.29e-16`。

对解析源 `q(t)=exp(2t)`，线性时间插值的积分误差从 2 段的 8.20% 降到
64 段的 0.00814%；末级收敛阶为 1.99993。对已声明的分段线性源模型，重新分步只改变舍入；
对未知的真实源，增加节点才会减少插值误差。未采到的快速变化不能由端点数据证明不存在。

## 真实 21cmFAST Qin20 源采样

同一 32³、种子 1234、Qin20 参数输入，在 **固定 z=8 的温度和电离反馈** 下，
调用原生瞬时 SFRD 和各时刻的扰动密度，取得 33 个等物理时间节点。
原生采样使用 4 线程，总耗时 13.28 s，未运行新的电离和热反馈历史。

时间采用积分后的原生 `dtdz` matter+Λ 定义；它与原生 SFR 中含辐射项的
`hubble()` 定义有明确区别，不能用末端 `dtdz × Δz` 替代。
起点为实际左极限采样时刻 `z=7.999999`，终点 `z=7.5`，时长约 57.3122 Myr。
它比严格 `z=8` 起算少约 107 年；这段偏移已明确记录，没有给偏移后的源值套用旧时刻。

下表的 L1 是逐格发射量差绝对值之和，除以 32 段梯形积分的总发射量。
发射量采用原生有效光子单位，不把它直接解释为已经吸收的氢原子数。

32 段 Simpson 积分为 **2833.188883**，与 32 段梯形的逐格 L1/Q 差为
`7.54e-6`（0.000754%）；这是两种有限采样积分的差异估计，不是严格误差上界。
ACG、MCG 的 Simpson 积分分别为 1777.359771、1055.829112。

瞬时率的细化积分与旧累计 `nion` 增量之比为 **0.499733**。因此之前发现的约一半差别
在增加时间采样后仍存在，主要不是这个区间的粗梯形积分误差。这是明确的源时间模型差别，
不能归因于光子输运或光子守恒修正本身，也不能推广成所有红移下的固定比例。

实际 32³ 源数组在第 13 段保存/恢复发射账本，再逐段完成积分。
与一次性积分的 L1/Q 差为 `4.05e-17`；再次推进到相同时刻的新增光子为零。

## 尚不包含的准确性

这里验证的是源率单位、时间插值和发射账本。固定反馈的采样不能验证真实反馈的时间收敛；
正在演化的密度也不能直接替换固定输运的原子场。物理 H/He 转换、气体平流、
在途辐射状态以及与电离/复合/温度的同步推进，仍由各自模块和最终耦合测试承担。
