# 有限光速与跨时刻光子状态：可执行修复及分离收敛验证

2026-10-23。代码为 `finite_c_packets.py`，独立保留原来的无限光速事件核。
这是固定气体、无复合、点源、灰色光子计数的研究参考；尚未接入 Qin20 反馈演化，
也不代表已找到与原生 21cmFAST 同成本的完整求解器。

## 修复了什么

原来把 `maximum_distance=c*dt` 当成因果输运、在下一步把留存光子从源重新发射，
都会改变到达时间或方向。本实现让光子包始终保留源、发射时间、原方向、射线路径游标、
剩余光子数及累计距离。排队事件使用 `t_arrival=t_emit+distance/c`。
源关闭以后，已经发出的光子继续传播；输出额外快照只观测既有队列，不重新生成光子。

- 每条射线用普通 DDA 记录实际交面；没有横向位置平均，也没有跨面几何位移。
- 未完全电离的体素在交面处消耗光子，消耗量不超过剩余中性容量。
- 同时到达同一体素的光子包按各自光子数分配容量，避免源插入顺序优先。
- 透明格只在无复合模型中永久跳过。模型不接受密度变化或复合造成的重新不透明。
- 达到数值最大距离的光子成为 `range_retained`，保留方向和累计距离；它们不计为逃逸。
- 总账本和逐源账本包含：已吸收、已逃逸、仍在途、距离截断留存。尚未到发射时刻的预定源不计入已发射。
- 源数量、时间、总光子预算和输出可表示范围有检查。超出默认两百万光子包预算或 float64 输出范围时，在修改发射计划前拒绝输入。

具体修复控制：

| 控制 | 结果 |
|---|---|
| 距离 0.5、c=1、持续源发射 0..1，观测 t=1 | 吸收 0.5、在途 0.5，修复原来的全部吸收 1 |
| 距离 4.5、c=2、发射 0..1，观测 t=3 | 吸收 0.75、在途 0.25；t=3.25 全部到达 |
| 同一源已关闭，但 t=2..3 到达目标 | 正确新增吸收 0.75 |
| 距离上限 3、目标距离 4.5，反复输出到 t=10 | 留存 1，吸收 0；累计距离仍为 3 |
| 一半光子朝远处 x、一半朝近处 y | 两边各吸收 0.5，不重新各向同性化 |
| 同时到达共享容量，入射量比 1:3 | 吸收份额 1:3，交换源插入顺序不变 |
| 同一发射计划增加或删除观测时刻 | 吸收及逐源分类逐位相同 |

模块的 16 个回归测试通过，包括薄交段、严格边界、周期回绕、大容量小吸收、极端总预算拒绝。
独立审计另外使用普通 DDA 和逐次交面队列，不复用候选的跳格和路径缓存，
在 16 个随机多源、开放/周期、有限范围案例中逐格及逐源分类一致。
独立证据见 `accuracy_acceptance.py` 与 `test_accuracy_acceptance.py`。

## 时间误差

持续发射用中点光子包近似：每段 dt 发射一包 `Qdot*dt`，时间为段中点。
这一发射离散必须细化；增加输出快照数量本身不会提高发射时间精度。
对于透明路径后不饱和目标，光子到达是时间阶跃，误差满足
`abs(N_packet-N_exact) <= Qdot*dt/2`。误差不必逐次单调，不能把光滑中点公式的二阶性质
直接用于非光滑电离前沿。

固定 15³ 网格、K=768、T=1，和同网格 512 个发射时间包比较：

| 发射时间段数 | 吸收场 L1 / 发射量 |
|---:|---:|
| 8 | 1.0972% |
| 16 | 0.2429% |
| 32 | 0.1174% |
| 64 | 0.0587% |
| 128 | 0.0335% |
| 256 | 0.0146% |

因此时间包误差已经与空间误差分开测量。固定网格的空间偏差不会因增加时间包而消失。

## 空间、角分辨率与连续有限光速球

解析参考为无复合、均匀气体中的相对论电离前沿：

\[
\dot Q(t-R/c)=\frac{4\pi}{3}n_H R^3.
\]

设置 `Qdot=c=T=1`、`nH=3/(4*pi)`，解析半径 `R=0.6823278038280194`。
参考吸收场采用连续球与每个体素的交体积，而非格心二值球。
固定物理盒宽 4.5、K=3072、128 个发射时间段，分别改变网格：

| 网格 | 格宽 | 等体积半径相对误差 | 吸收 L1 / 解析电离原子数 |
|---:|---:|---:|---:|
| 9³ | 0.5 | +12.366% | 54.817% |
| 15³ | 0.3 | +8.338% | 29.476% |
| 21³ | 0.214286 | +6.291% | 22.856% |
| 33³ | 0.136364 | +3.799% | 13.217% |
| 45³ | 0.1 | +2.583% | 8.776% |

这是正的体素交面集中吸收误差：整格原子在入射交面消耗光子，会使粗网格的等体积前沿偏大。
它随空间细化下降；没有把“到达时间正确”写成“连续空间形态已经准确”。
所有已测吸收都位于 `ct+sqrt(3)*dx` 范围内。这个界明确包含体素代表误差，
并不声称整格集中吸收严格位于连续 `ct` 球内。
体积参考的 24/48 点积分差在最细网格为解析原子数的 `6.49e-5`，小于被测空间误差。

固定 21³、128 个发射时间段，K=48/192/768/3072 相对 K=12288 的吸收场 L1/Q
分别为 **10.5268%、2.0597%、0.6624%、0.2455%**。
这与空间、时间矩阵使用不同控制变量；不把角收敛当作网格收敛。

最细 45³ 网格再把 K3072 提高到 K12288，吸收场差为发射量的 **0.5628%**；
半径误差从 +2.5832% 变为 +2.6167%，连续球形态误差从 8.7757% 变为 8.8353%。
因此最细网格的正半径偏差仍主要是体素交面闭合，增加角数没有将其消除。
这个额外交叉检查用两个独立进程，结果记录在 `finest_grid_angular_check`。

## 成本与未覆盖项

验证脚本把相互独立的参数点分配给四个进程；单个包求解器仍是串行参考。
大角数保留大量在途光子：21³、K12288、128 个发射时间段共生成 1,572,864 包，
本轮该参数点约 69 s；45³ 同样的 K 和时间包数约 116 s。共享主机并行测量只用于说明参考规模，不能用来声称生产加速。

本模块没有复合、有限光深格内吸收、频谱、宇宙膨胀红移、密度平流或原生热/UV反馈。
有限光深化学模块与这个不可逆透明前沿不能直接拼接；复合需要允许光子路径重新遇到吸收者。
后续生产实现可以用延迟连续束或合并有严格相同位置/方向/时间区间的包减少内存，
但不得把不同角度、不同发射时间或不同光程的光子重新合并为源总量。
