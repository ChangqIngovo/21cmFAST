# 独立时空准确性验收

2026-10-23。这里的验收独立于各实现自己的测试，代码为
`accuracy_acceptance.py`，结果为 `validation_accuracy_acceptance.json`。
它检验明确声明的离散模型和近似，不构成完整秦20演化的准确性证明。

## 独立比较

| 项目 | 独立控制 | 结果 |
|---|---|---|
| 空间坐标变换 | 轴置换、反射、周期平移，方向与网格共同变换 | 5组，最大场差 `1.78e-15` |
| 时间单位变化 | 源率乘 `1e-290` 到 `1e290`、时间除同一因子，发射历史不变 | 9组，最大场差 `3.55e-15` |
| 有限光速跨步状态 | 预先枚举全部交面，再按时间扫描；不复用候选的队列、透明跳跃或路径缓存 | 16组开放/周期多源脉冲，逐格及逐源各类别一致 |
| 斜射线空间交段 | 对每个体素独立求射线与盒子交集，不做DDA遍历 | 48组，最大交段长度差 `1.11e-16` |
| 源时间插值 | 插入37个时间节点，再用71个输出时刻分步累计 | 积分误差0，累计差 `1.53e-15` |
| 有限光深多源复合 | 与独立同时入射的Radau ODE比较 | 最大电离度差 `1.10e-8` |
| 源顺序敏感性 | 反转全部射线顺序，保持同时发光历史 | 最大电离度差 `5.04e-10` |
| 无复合平行光柱细分 | 固定总原子数和总光深，分成1、2、8、32格 | 总吸收量差 `2.22e-16` |

最后一项验证的是柱积分的解析不变性，不表示格内电离度分布在所有情况下已经空间收敛。
有限光速比较的是同一脉冲离散化，持续源还必须单独做发射时间细化。

## 审计中发现并推动修复的问题

旧事件接口接受有限输入，但总源率或总发射量可以在中间运算溢出。例如
`rate=1e308, duration=10` 返回成功和 `NaN` 光子账本；
`rate=1e-320, K=49152` 可把全部逐角发射率舍入到零。
现在不支持的数值尺度在进入C++之前拒绝，并提示改用合适单位。
修复后的9组时钟缩放说明，在支持的尺度内不会因换单位改变吸收图。

有限光速新接口也曾把两次 `1e308` 发射或一个 `1e308×10` 区间转成无穷输出，
同时内部长双精度账本仍显示零误差。现在在修改发射队列之前检查累计可表示范围。
透明单元的Gamma曾出现 `infinity×0=NaN`；极强复合也有中间乘积溢出。
这些运算已修复。无法由浮点电离度承载的小原子增量现在显式报告精度未满足，
而不把一个未改变的状态标成已完成化学更新。

## 角收敛不是任意空间结构的误差上界

独立反例使用96³盒子，源在 `(1,48,48)`，只有 `(94,48,48)` 单元有不透明容量。
源向该单元发出的真实方向份额可由近端正方形面的立体角精确求得：

\[
f_\Omega=\frac{1}{\pi}\arctan\frac{1/4}{d\sqrt{d^2+1/2}}
=9.300236259834016\times10^{-6},\qquad d=92.5.
\]

K=3、12、48及两组旋转都没有命中该单元。修复前控制器在各图吸收量均为零时，
将相邻差为零报告为经验收敛，即使要求的绝对误差只有 `1e-12`。
这表明：**任意有限组方向相互一致，不足以证明没有共同漏掉的结构。**
当前验收脚本保留这个反例；新增保护使它返回 `unresolved`，原因是
`zero_absorption_coverage_unresolved`，不再接受这个全零命中结果。
修复全零命中情况后，部分漏掉的小云仍可能逃过经验比较。
严格通用的方向误差界需要进一步给角元积分误差、可见性区间或未解析结构设上界。

## 完整模型仍需哪些独立证据

| 准确性层次 | 当前验收范围 | 不能由此推出 |
|---|---|---|
| 事件核 | 固定气体、无限光速、锐利不透明格前沿 | 复合、热演化、有限光速成立 |
| 角控制 | 细化和旋转的经验一致性、失败时拒绝 | 任意细小遮挡物都在给定误差内 |
| 网格 | 球、交段、柱积分和斜射线的专项检验 | 所有密度场及观测量均空间收敛 |
| 源时间历史 | 明确瞬时率的正积分、跳变与追加历史、无重复花费 | Qin20旧累计代理量与新瞬时率是同一源模型 |
| 有限光速 | 脉冲发射、固定单调透明度、持久在途状态 | 已与有限光深复合同时耦合 |
| 有限光深复合 | 同时多源、固定温度纯氢、无限光速 | 原生自屏蔽、He、热过程和反馈已经正确 |
| 原生反馈和气体运动 | 改变固定原子场时明确拒绝 | 密度平流、跨快照反馈、完整21cm信号已经验证 |

这些层次需要分别满足，账本闭合不能代替空间形态、传播延迟或物理闭合检验。
