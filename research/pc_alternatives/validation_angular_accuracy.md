# 角分辨率与范围控制：修复与验证

2026-10-23。只修改研究入口，不改生产 `global-budget` 或 C++ 事件核。

## 修复

新增 `angular_accuracy.solve_controlled`。它保留单次事件求解器的原始吸收场，
逐级增加方向数，每级另用两个非轴向旋转重算。要求连续两级同时满足：

- 相邻角分辨率的吸收场 L1 差低于 `angular_atol + angular_rtol × Q`；
- 同一级所有方向相位之间的差也低于该值；
- 逐源吸收、逃逸、留存分类的合计 L1 差也通过；
- 有限搜索范围的原子数 L1 上界通过独立范围容差。

默认角容差 3%，范围容差 0.1%。这两个数是声明范数下的数值控制参数。
角检查只是**经验收敛**，没有把相邻两次计算的差值当成真实连续解误差上界。
上限内未通过时默认抛出 `AccuracyNotReached`，附带最后一个结果及诊断；
显式请求返回失败结果时仍标记 `unresolved`。

已知的全零盲点另设失败检查：正源和正吸收容量存在、但所有角规则均零命中时，
不能只因几次零图一致而通过；除非总可能吸收量本身已低于请求容差。
96³ 中源 `[1,48,48]`、吸收格 `[94,48,48]` 的解析吸收份额为
`9.30023625983e-06`，K=3→12→48 及旋转全部漏采。
请求 `1e-12` 精度时现在明确返回 `zero_absorption_coverage_unresolved`。
**这个检查没有解决所有盲点：已有其他吸收时，未被采样的小特征仍可能漏掉。**

默认 512 MiB 角向存储上限在分配前检查：按每个正源都生成 K 条 64-byte 射线、
4096 条分块及方向数组工作区估计。它可能高估延迟生成射线的实际成本。
网格、堆和各相位缓存不在这项上限内，因此这不是完整进程内存保证。
若第一次求解就被拒绝，数组字段为 `None`，不会伪造全零物理解。

## 空间与角误差分离

原来 R=8 格、128³ 大盒子的 K48 结果没有逃逸，但球形 L1/Q 误差为
**156.9608%**。新入口拒绝 K48，接受 K49152 后降至
**5.6805%**。
继续计算 K196608，吸收图差为 **0.2386% Q**；
另一个未参与控制的旋转差为 **0.3651% Q**。

相同物理球半径、逐渐减小格宽，每个网格单独通过角检查后：

| R/格宽 | 最终 K | 连续球体素积分参考的 L1/Q |
|---:|---:|---:|
| 4 | 49152 | 11.4260% |
| 8 | 49152 | 5.6805% |
| 12 | 196608 | 3.9594% |
| 16 | 196608 | 2.9723% |

3% 的角检查不意味着总连续误差小于 3%。R=4 的约 11.4% 残差仍来自粗格上的
不透明前沿表示。上述序列证明这组球测试的空间细化改善，没有证明任意密度场、
任意发射位置及任意前沿拓扑的统一误差界。

## 多源、遮挡与范围

两个源、非均匀容量及高密度平板算例通过控制后，对独立旋转的 K196608 参考，
吸收图差为 **0.1792% Q**。
该参考属于同一离散前沿模型，不是完整 RT 真值。
另一双源不透明平面测试的背后吸收严格为零。
数值范围从 0.25 格自动延至 16 格，留存清零。

范围控制使用固定源历史、静态容量、无复合、无限光速模型的单调性结果：

\[
\|A_{L'}-A_L\|_1\leq\min(R_L,C_{\rm remaining}),\quad L'>L.
\]

它只约束继续延长相同射线时的原子数吸收图变化，不约束相对功率、有限光速、
热反馈或复合误差。搜索上限不是物理平均自由程，也不能设为 `cΔt` 后解释成因果输运。

## 代价与复现

本轮共享主机上 128³ 大盒子的单次 K48 核为
0.148 s；整个多级、多相位控制为
7.187 s。
该保守控制会重复透明距离预处理，尚未优化；这些数字不能支持“达到相同精度后成本不增加”。
每个源使用同一个高 K 也不是最终低成本自适应角区方案。

本文件对应的 **26 项控制器回归通过**；每个通过结果另核查逐源、逐角和总体账本。
完整数值、每级误差、范围扩展记录、存储限制及代码 SHA256 均在
[validation_angular_accuracy.json](validation_angular_accuracy.json)。

```bash
python research/pc_alternatives/validation_angular_accuracy.py
python -m pytest -q research/pc_alternatives/test_angular_accuracy.py
```

本次没有声称完成有限光速、复合、真实秦20源历史、热反馈或所有空间构型的检验。
这些必须由相应时间/物理验证单独判断。
